# Hi, I'm Ankit 👋

I build **AI evaluation systems, agentic workflows, and reliable ML/LLM applications**.

My recent work focuses on long-horizon coding-agent evaluation, deterministic verification,
RAG systems, local LLM inference, and production-style Python backends.

## Featured projects

### [Agent Reliability Lab](https://github.com/ankitkarwasara5/agent-reliability-lab)
Reproducible evaluation for long-horizon AI coding agents with deterministic Docker
verification, failure attribution, repeated-trial reliability metrics, and stagnation detection.

**Highlights:** long-horizon benchmark suite · pass@k / repeatability metrics · Docker sandbox ·
Ollama + Groq comparison · model-vs-infrastructure failure separation

### [Local AI Learning Tutor](https://github.com/ankitkarwasara5/local-ai-learning-tutor)
Local-first learning application that generates structured curricula and lessons with Ollama,
validates model output with Pydantic schemas, persists progress in SQLite, and degrades
gracefully when the model is unavailable.

**Highlights:** structured LLM outputs · FastAPI · SQLite · local inference · deterministic tests ·
offline fallback

### [Agentic RAG Research Assistant](https://github.com/ankitkarwasara5/agentic-rag-research-assistant)
Agentic research workflow that plans a research task, gathers web/document evidence,
retrieves relevant context, produces citation-backed reports, and evaluates output quality.

**Highlights:** LangGraph · hybrid retrieval · ChromaDB · Ollama · citation checks ·
evaluation/revision loop
